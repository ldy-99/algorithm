## 📝 복습 노트
- arr = [2,6,8,14] 와 같은 형태일 때 , lcm(*arr) 으로 N개의 최소공배수를 바로 구할 수 있다.  
- 두 수 일때 공식 : $\text{LCM}(a, b) = (a \times b) / \text{GCD}(a, b)$
- 문제에서 원형 구조일때 , 수직선 배열의 확장을 생각할 수 있으며 그리디가 애매할때는 문제의 제한범위를 보고 순열 기반의 완전탐색을 생각할 수 있다.
- heap을 쓸 수 있는 상황을 잘 파악해보자(매번 큰 값이나 작은 값을 찾을 때)
- 최소 동전의 개수를 구하는 문제 vs 돈을 거슬러 주는 방법의 경우의 수를 구하는 문제
- dp[i] = min(dp[i] , dp[i-coin] + 1 ) vs dp[i] += dp[i-coin]
- for right in range(n): -> while 조건식 :  # 정답 갱신 , 왼쪽 원소 제거 , left += 1 와 같은 구조를 알아두면 좋다.
